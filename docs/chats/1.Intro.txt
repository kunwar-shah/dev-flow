3. ARCHITECTURE DECISIONS

Core Technology Stack


Shell: Bash 4.4+ (available in Ubuntu 24.04)

Configuration: JSON (via jq) for structured data

Package Manager: APT (Ubuntu native)

Service Manager: systemd

Testing: BATS (Bash Automated Testing System)


Key Architectural Decisions

1. Native Services vs Docker

Decision: Use native services for LAMP stack (Apache, PHP, MySQL)

Rationale:

Faster startup and execution

Lower memory footprint

No Docker complexity for basic needs

Solves /mnt performance issues



Trade-off: Less isolation, but Docker available for special DB versions


2. Configuration Management

Decision: JSON-based configuration with shell wrappers

Rationale:

Structured, parseable data

Easy to extend

Can be edited manually if needed

jq widely available




3. Site Registry

Decision: Central site registry (etc/sites.json)

Structure:


{
  "sites": [
    {
      "name": "myproject.test",
      "path": "/home/user/websites/myproject.test",
      "docroot": "public",
      "php_version": "8.2",
      "ssl_enabled": true,
      "created": "2025-01-15T10:30:00Z",
      "status": "active",
      "database": {
        "type": "mysql",
        "name": "myproject_db",
        "host": "localhost",
        "port": 3306
      }
    }
  ]
}

4. Modular Command Structure

Decision: Subcommand-based CLI (like git)

Example: devflow site create myapp.test php8.2

Benefits: Intuitive, extensible, self-documenting


5. SSL Certificate Management

Decision: Self-signed CA + per-site certificates

Flow:

Create root CA on first SSL operation

Generate per-site certificates signed by CA

Provide instructions to trust CA in browsers

Automatic certificate generation with site creation




6. PHP Version Management

Strategy: Multiple PHP-FPM instances via Ondřej PPA

CLI switching: update-alternatives + wrapper functions

Per-site: vhost socket configuration


7. Service Management

Decision: Wrapper around systemctl with health checks

Features:

Status dashboard

Automatic startup configuration

Service dependency tracking

Graceful restarts




8. Backup Strategy

Decision: File + database combined backups

Format: Compressed tar.gz with metadata JSON

Storage: Local + optional remote sync

Retention: Configurable (default: 30 days)
